## Evaluation context

The selected result is measured on ScanQA's test-with-objects split. EM@1 increases by 1.07 percentage points over 3D-VisTA. See [Table 2 in the paper](https://arxiv.org/html/2507.01800v1) for the full set of metrics.

The code link points to the collaborative research repository maintained by the project team.
